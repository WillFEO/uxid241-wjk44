# uxid241-wjk44

## Project Description - Cookbook

A server-side online cookbook built with PHP and MySQL for UXID232 (Scripting for IDM II) at Drexel University. It servers visitors, who can browse, search, and filter a library of recipes and can view each recipe without logging in, and admins, who log in to a password-protected area to add, edit, and delete recipes. The app will be built incrementally across the term, so these features are in progress.
